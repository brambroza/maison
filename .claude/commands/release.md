ปล่อย release ตามขั้นตอน ($ARGUMENTS = ชิ้นที่เปิดตัวรอบนี้):

## 1. ตรวจก่อนปล่อย
- `git status` ต้องสะอาด · ถ้ามี branch `piece/NNN` ค้าง ให้ merge เข้า main ก่อน (ถามผู้ใช้ยืนยัน)
- รัน `pnpm test && pnpm lint && pnpm typecheck && pnpm build` — ไม่ผ่าน = หยุดทันที รายงาน ห้ามปล่อย

## 2. ปล่อย
- **ถามยืนยันก่อน push เสมอ** แล้ว `git push` (Vercel auto-deploy จาก main)
- รอ deploy เสร็จ (~1-2 นาที) แล้วตรวจ production https://maison-go.vercel.app:
  - หน้าใหม่ `/n/NNN` ตอบ 200
  - `/api/og?id=NNN` ตอบ 200 image/png — ดาวน์โหลดรูปมา Read ดูด้วยตา
  - og:image ใน meta ชี้โดเมนถูกต้อง
  - `/sitemap.xml` มี URL ชิ้นใหม่

## 3. ร่างประกาศเปิดตัว (ร่างให้ผู้ใช้อนุมัติ — ห้ามโพสต์เอง)
เขียนลง `content/scripts/NNN-launch.md`:
- **แคปชัน Facebook** — น้ำเสียงราชกิจจานุเบกษา ประกาศเปิดตัว "ชิ้นงานในคอลเลกชัน" จบด้วย URL รายชิ้น
- **สคริปต์ TikTok 1 คลิป** (โครง: hook 3 วิ → โชว์เล่นจริง → จบด้วย URL) ตามเสาคอนเทนต์ Luxury Unboxing
- **ข้อความตอบคอมเมนต์** สั้น ๆ 2-3 แบบ ในเสียงบัตเลอร์
- กติกา: เรียกผู้ชม "ท่านสมาชิก" · ไม่มีอิโมจิยกเว้น ✦ · ไม่พูดถึงเทคโนโลยี · ทุกคลิปจบด้วย URL รายชิ้น ไม่ใช่หน้า portal

รายงานจบ: สถานะ production + ไฟล์ประกาศที่ร่างไว้ + สิ่งที่รอผู้ใช้อนุมัติ
