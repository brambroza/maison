งานการ์ดแชร์ของชิ้น Nº $ARGUMENTS:

## ความรู้ก่อนแตะ (สำคัญ)
- การ์ดไม่ได้ใช้ next/og — ประกอบ SVG เองใน `apps/web/lib/og-card.ts` แล้ว render ด้วย resvg
  (เหตุผล: satori วางวรรณยุกต์ไทยผิด ดู comment หัวไฟล์) — **ห้ามเปลี่ยนกลับไป next/og**
- เลย์เอาต์ทั้งใบอยู่ที่ `renderCardSvg` · เนื้อหาต่อชิ้นมาจาก `toOutcome` ใน `NNN.logic.ts`
- ตัดบรรทัดด้วย `wrapText` ซึ่งประมาณความกว้าง — ข้อความยาวมากอาจล้น ต้องดูรูปจริงเท่านั้นถึงรู้
- ฟอนต์: Mali (display) + Mitr (body) ใน `apps/web/assets/fonts/` — อักขระนอกฟอนต์ (เช่น ✦ อิโมจิ) จะเป็นกล่องเปล่า ห้ามใช้ในข้อความการ์ด
- สีต้องมาจาก `COLORS` ใน `lib/brand.ts` เท่านั้น

## ขั้นตอน
1. `pnpm build` แล้ว start server (`npx next start -p 3100` ใน apps/web)
2. render ครบทุก state สำคัญของชิ้นนั้น:
   - แบบเปล่า: `/api/og?id=NNN`
   - ทุกค่า v (0 ถึง verdictCount-1) พร้อม s ตัวอย่าง และ t ถ้าชิ้นนั้นรองรับ
   - เคสสุดขั้ว: s ตัวเลขยาวสุด, t ยาวสุด 40 ตัวอักษร, verdict บรรทัดยาวสุด
3. Read รูปทุกใบดูด้วยตา — เช็ค: ล้นกรอบไหม วรรณยุกต์ครบไหม สมดุลช่องว่างดีไหม
4. แก้ตามที่ผู้ใช้สั่ง (หรือรายงานปัญหาที่เห็นถ้าไม่ได้สั่งอะไรเจาะจง)
5. แก้แล้ว render ซ้ำจนพอใจ + `pnpm test` (มี test ครอบ og-card)
6. ส่งรูป before/after ให้ผู้ใช้ดู commit เมื่อผู้ใช้พอใจ

หมายเหตุ: การ์ดฝั่งเว็บ (`components/ResultCard.tsx`) ต้องดูสอดคล้องกับการ์ดแชร์ —
ถ้าแก้ดีไซน์ใหญ่ ให้แก้ทั้งสองที่
